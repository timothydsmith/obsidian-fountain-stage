---
title: "Commands"
description: "Every Fountain Stage command, and where it is in a script's More options menu."
---

Every command is in the command palette, as **Fountain Stage: …**. Those you'll want most are in a script's **More options** menu too, in sections: drafts, rehearsal, cast, panels and focus. A toggle, such as **Toggle typewriter mode**, is in the menu without "Toggle", with a tick when it's on. Commands show only where they apply: **Restore cut** in a cuts file, say, or **Stop sprint** while a sprint is going.

You can give any command a hotkey in **Settings → Hotkeys**, or add it to the mobile toolbar in **Settings → Mobile**.
