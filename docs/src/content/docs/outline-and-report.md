## Script outline

Fountain Stage has a script outline of its own in the sidebar, since Obsidian's outline only reads notes. It shows the script **by act** (acts, then scenes, then action beats) or **by beat** (story beats, then scenes, then action beats), with any synopsis (`= …`) under its heading and how long each runs. Click one to go there, or drag a scene or beat to move it. On a phone, or anywhere, right-click a scene or press and hold it for **Move scene up** and **Move scene down**. The part you're in is highlighted, and the outline updates as you type. It opens in the right sidebar the first time you open a script in the vault (on a phone, it's added to the right sidebar without opening it). If you close it, bring it back with **Show script outline**. See [Story outline](../story-outline/) for planning a play in it.

## Script report

**Show script report** opens a report on the script in a tab beside it. It follows the script you're in and updates as you write. Click a character or scene to go there.

- **Totals:** pages, runtime, silence (the pauses the script asks for, added up), words spoken, speeches, acts, scenes, characters and the smallest cast.
- **Characters:** each one's speeches, words, share of the dialogue, time speaking, number of scenes, and first and last scene.
- **Scenes:** each one's act, pages, runtime, silence, speeches, words and characters. Scenes are scene headings, and acts with no scenes in them. Sections never make a scene. Text before the first scene is a scene of its own.
- **Who's in each scene:** a chart of characters against scenes. A character is in a scene if they speak there or are named in a stage direction or parenthetical.
- **Doubling:** characters who never share a scene, so one actor could play both.
- **Smallest cast:** the fewest actors who can play every part, and one way to share the parts out. Type a cast size to see whether it can play the script, and which scenes have too many characters for it.

The button at the top of the report, or **Save script report as note**, saves it as a Markdown note beside the script (`Script - Report.md`), replacing an earlier one.
